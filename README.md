# 🎮 GenAI Game

## About the Project
This project is a game developed using Generative Artificial Intelligence (GenAI).

## Project File
- `gen ai games.ipynb` — Jupyter Notebook containing the game code.

## Technologies Used
- Python
- Jupyter Notebook
- Generative AI

## How to Run
1. Download the notebook from this repository.
2. Open it using Jupyter Notebook, Google Colab, or VS Code.
3. Install any required libraries.
4. Run the notebook cells in order.

## Features
- Game logic implemented in Python
- Generative AI-based functionality
